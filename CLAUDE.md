# thematrixisadocumentary.com

Author marketing site for the book **"The Matrix is a Documentary — A Journey of
Awakening, Remembering, and the Key That Frees the Soul"** by Jack Amorino.

## Stack
- **Framework**: Next.js 15 (App Router, TypeScript)
- **CMS**: Sanity (embedded Studio at `/studio`; schemas in `src/sanity/schemaTypes`)
- **Hosting**: Vercel
- **Styling**: plain CSS with design tokens in `src/app/globals.css` (no Tailwind)

## Project layout
- `src/app` — App Router pages, `layout.tsx`, `globals.css`, `sitemap.ts`, `robots.ts`, `feed.xml/`
- `src/components` — shared UI (nav, footer, buy buttons, email capture, video/blog cards)
- `src/lib` — Sanity client/queries/image, SEO + JSON-LD helpers, buy links (UTM), fallback seed content
- `src/sanity` — embedded Studio config + schema types
- `public/assets` — book art supplied by the author

## Content model
Blog posts are the book's **Keys** (three Cycles + the Key of Love). Videos power the
"Decode The Real" band and `/videos`, both gated behind the `showVideos` site setting.
When Sanity is empty or unconfigured, pages fall back to seed content in
`src/lib/seed-content.ts` so the site always renders.

## SEO / GEO
- Per-page Metadata API + canonical URLs on `NEXT_PUBLIC_SITE_URL`
- JSON-LD: `Book` (home/the-book), `Article`+`Person` (posts), `VideoObject` (videos), `BreadcrumbList`, `WebSite`
- `sitemap.xml`, `robots.txt`, and `/feed.xml` (RSS) generated by the app
- All content SSR/SSG; manuscript phrasing preserved verbatim for AI-answer extraction
